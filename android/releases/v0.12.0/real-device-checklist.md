# v0.12.0 real-device checklist

1. 历史页在 20、50、全部之间快速切换；检查当前范围有文字“已选”状态，旋转屏幕后页面内选择仍保留。
2. 对拥有数千条历史的单个视频选择“全部”；确认首尾、明显峰值和突变仍可见，提示仅说明“已优化显示”，历史列表与导出记录数不变。
3. 验证单项趋势的手动/自动采集点形状、点按提示和跨时区时间显示。
4. 验证点赞÷播放、评论÷播放、投币÷点赞；确认分子/分母方向明确、同一指标不能选为两端、零分母和缺失值显示“当前无法计算比值”。
5. 在小屏、横竖屏、大字体和深色模式检查三张同步比值图的阅读性、滚动和点按提示。
6. 连续手动与自动采集后，确认最近快照只与同一视频的上一条有效快照比较；验证 ↑ 正增、↓ 负增、— 0、首次记录和字段缺失。
7. 验证已有封面、无封面、断网、失效 URL 和快速滚动；封面失败必须仅显示“暂无封面”，不能阻止添加、刷新、详情或打开视频。
8. 从 v0.11.2 的数据库升级，确认既有快照排序、历史导出/导入和封面为空时的首页均正常。
9. 在 Android 与 Windows 双向导入含/不含 `coverUrl` 的历史 ZIP；旧 ZIP 不得因缺少封面拒绝导入。
