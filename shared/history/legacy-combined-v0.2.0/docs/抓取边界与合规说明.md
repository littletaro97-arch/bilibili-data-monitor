# 抓取边界与合规说明

## 项目边界

本项目只用于本地、低频、透明地观察 B 站公开视频的公开统计数据。

必须遵守：

1. 只处理公开视频的公开数据。
2. 不绕过登录。
3. 不绕过验证码。
4. 不绕过平台风控。
5. 不使用代理池。
6. 不进行高频采集。
7. 不采集私人数据、私信、账号后台、付费内容或会员限制内容。
8. 不硬编码 Cookie、账号、密码。
9. 不把敏感配置提交到 Git。
10. Android 端受系统后台限制，不能承诺稳定长期后台高频监控。

## 网络请求规则

- 请求必须低频、可解释、可停止。
- 请求必须设置超时。
- 请求失败必须记录本地日志。
- 遇到 403、412、验证码、风控、登录要求或异常响应结构时，任务必须停止或进入冷却。
- 不自动搜索、拼接或切换未确认接口。
- 不实现代理池、IP 轮换、设备指纹伪造或 App 签名模拟。

## 敏感数据规则

不得提交：

- `config.toml`
- `.env`
- Cookie
- 账号、密码、token
- `data/*.db`
- `data/exports/`
- `logs/*.log`
- `reports/output/`
- 真实用户数据、截图或完整响应样本

## 技术风险

- B 站接口变化导致请求失败。
- 网页结构变化导致解析失效。
- 平台风控返回 403、412、验证码或登录要求。
- Android 后台限制导致定时任务不准。
- 网络异常导致快照缺失。
- 本地 SQLite 数据库膨胀。
- 图表数据过多导致页面卡顿。
- Windows 端和 Android 端数据格式不一致。
- 局域网访问配置不当导致本地数据暴露。

## 处理原则

当功能需求与以上边界冲突时，优先缩小功能范围，而不是增加绕过机制。
