# v0.10.0 实机测试清单

## 通知

1. 在设置中开启通知，确认“权限状态=已授权”“渠道状态=可用”。
2. 点击“发送测试通知”，预期立即收到一条通知，且快照数量和正式通知间隔不变化。
3. 在系统设置关闭该渠道后重试，预期显示“通知渠道已关闭”并可打开系统通知设置。
4. 分别执行手动采集、自动采集，验证每次检测与定时汇总模式、无结果、间隔未满足和防重复。
5. 在前台、后台、锁屏和应用被回收后验证通知；点击通知应只打开一个应用页面。

## 自动刷新

1. 依次设置 1、3、5、10 分钟，保持应用前台，按日志核对实际间隔。
2. 切入后台和锁屏，确认界面没有承诺短周期准时执行；后台按系统最低 15 分钟能力观察。
3. 依次设置 15、30、60、120 分钟，重启应用，确认值恢复且唯一 WorkManager 没有重复任务。
4. 分别从低间隔切到高间隔、从高间隔切到低间隔，检查没有重复请求。

## 首页与历史趋势

1. “详情”应进入应用内详情；“打开”应优先由已安装的 B站 App 处理，无 B站 App 时由浏览器处理。
2. 用纯 BV、手机分享链接、精准空降链接添加视频后测试打开；快速重复点击不应闪退。
3. 手动采集显示“手动采集”，自动任务显示“自动采集”，升级前旧记录显示“历史数据”。
4. 检查快照紧凑高度、趋势图空间、20/50 条切换、自动/手动点型、大字体、小屏、横屏、深色模式与滚动流畅度。
