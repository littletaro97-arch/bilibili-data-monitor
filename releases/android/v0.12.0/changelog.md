# v0.12.0

- 历史趋势范围新增“全部”，并采用按时间桶保留首尾/极值的轻量降采样，原始快照不会被删除。
- 新增双指标比值分析：显示两个原始指标和比值；零分母、缺失字段和同指标选择都会安全处理。
- 最近快照显示相对上一条有效快照的增加、减少、无变化、首次记录或暂无对比状态。
- 从 B站 view API 的 `data.pic` 读取封面 URL；首页缩略图使用 HTTPS 域名校验、受控内存与磁盘缓存、统一占位。
- Room 升级至 v4，新增封面 URL 与绝对采集毫秒；历史交换格式保持 v1，封面字段可选且 Windows/Android 兼容。
- 本版本未更改 WorkManager、前台服务、通知保活、息屏调度或电池权限逻辑。
