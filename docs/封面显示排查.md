# Android 首页封面显示排查

截至 v0.12.2，Android 已从 B 站视频接口的 `data.pic` 读取封面 URL，持久化到 `videos.coverUrl`，并在首页用受限的 HTTPS CDN 图片加载器显示，因此不存在“没有封面字段或没有加载链路”的问题。新添加的视频会先以空 `coverUrl` 入库，只有一次成功刷新返回有效 `data.pic` 后才会补齐；接口缺少该字段、非 HTTPS/非 B 站 CDN 地址、网络请求失败或图片解码失败都会统一显示“暂无封面”。当前没有可用模拟器、实机或运行日志，无法把某个实际占位案例归因为其中任一条件，故本轮不伪造接口字段或添加未经证实的重试逻辑。图片缓存仍限定为内存 8 MiB、磁盘 24 MiB、单次下载 2 MiB，并不影响添加视频或快照采集。
