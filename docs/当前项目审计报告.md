## 不建议立即做的重构

不建议现在把 Windows 端源码整体移动到 `windows/app/`。原因：

- `app/config.py` 使用 `Path(__file__).resolve().parents[1]` 推导项目根。
- 数据库、报告输出、配置文件都依赖项目根路径。
- 测试和启动命令当前以根目录 `app/` 为包路径。
- 立刻移动会把目录整理任务变成路径兼容性重构，风险超过收益。

更稳的方案是先保留 Windows 端原结构，新增 `docs/`、`android/`、`shared/`、`versions/` 和 `scripts/`，再按版本逐步抽象共享数据格式。
