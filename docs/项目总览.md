# 项目总览

## 定位

B 站公开视频数据监控是一个本地优先的低频数据采集、存储、分析和导出工具。

当前成熟端是 Windows 本地 Web 面板；Android 端处于规划阶段，后续只做透明、低频、本地存储的 MVP。

## 当前技术栈

- FastAPI
- SQLite
- APScheduler
- httpx
- Jinja2
- Plotly
- pandas
- pytest

## 当前目录策略

暂不移动现有 Windows 端源码，保留：

```text
app/
data/
reports/
```

新增长期维护目录：

```text
docs/
android/
shared/
versions/
scripts/
```

## 后续方向

- Windows 端：稳定性、测试、导出格式、图表性能。
- Android 端：MVP 原型、Room、手动刷新、低频定时、前台服务通知。
- Shared：冻结 CSV/JSON 字段，避免双端数据漂移。
