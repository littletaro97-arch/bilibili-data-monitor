# 版本迭代记录

## 版本规则

- `v0.1.x`：原始 Windows 端功能整理与 bug 修复。
- `v0.2.x`：Windows 端稳定性优化、文档完善、测试补充。
- `v0.3.x`：Android 端 MVP 原型。
- `v0.4.x`：Android 端实机调试、通知、前台服务、本地存储优化。
- `v0.5.x`：Windows + Android 数据格式统一。
- `v1.0.0`：双端基本稳定版。

## Git 规则

- 小改动使用短分支，避免直接堆在 `master`。
- Android 大改使用 `android-mvp` 或 `codex/android-mvp-*`。
- Windows 稳定性修复使用 `windows-stabilize` 或 `codex/windows-stabilize-*`。
- 共享数据结构使用 `shared-schema` 或 `codex/shared-schema-*`。
- 文档整理使用 `docs-cleanup` 或 `codex/docs-*`。
- 不把 Android、Windows、共享 schema 三个方向的大改混在一个提交里。

## v0.3.0

- 版本号：v0.3.0
- 日期：2026-07-07
- 改动目标：创建 Android MVP 原型，不破坏 v0.2.0 Windows 基线。
- APK 输出路径：`releases/android/v0.3.0/bilibili-monitor-android-v0.3.0-debug.apk`

### 新增功能

- 新增 Android Gradle 工程，位于 `android/`。
- 新增 Compose 单 Activity MVP：视频输入、详情、历史、导出、日志页面。
- 新增 BV 号/视频链接解析。
- 新增 OkHttp 手动刷新 `x/web-interface/view` 基础视频数据。
- 新增 Room 本地数据库：视频、快照、日志。
- 新增 JSON/CSV 本地导出，字段尽量对齐 shared schema。
- 新增 Android 单元测试：BV 解析、接口 JSON 映射、CSV 头和转义。
- 新增 Debug APK 打包产物。

### 修改内容

- `.gitignore` 增加 Android 构建产物、`local.properties`、APK 忽略规则。
- `android/README.md` 增加工程说明、构建命令和 v0.3.0 范围。
- `docs/Android端规划.md`、`docs/debug记录.md`、`docs/实机测试记录.md`、`docs/开发任务清单.md` 增加 v0.3.0 内容。
- `README.md` 增加双端目录隔离和 Android MVP 说明。
