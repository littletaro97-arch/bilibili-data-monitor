# 版本迭代记录

## 版本规则

- `v0.1.x`：原始 Windows 端功能整理与 bug 修复。
- `v0.2.x`：Windows 端稳定性优化、文档完善、测试补充。
- `v0.3.x`：Android 端 MVP 原型。
- `v0.4.x`：Android 端实机调试、通知、前台服务、本地存储优化。
- `v0.5.x`：Windows + Android 数据格式统一。
- `v1.0.0`：双端基本稳定版。

## Git 规则

- 小改动使用短分支，避免直接堆在 `master`。
- Android 大改使用 `android-mvp` 或 `codex/android-mvp-*`。
- Windows 稳定性修复使用 `windows-stabilize` 或 `codex/windows-stabilize-*`。
- 共享数据结构使用 `shared-schema` 或 `codex/shared-schema-*`。
- 文档整理使用 `docs-cleanup` 或 `codex/docs-*`。
- 不把 Android、Windows、共享 schema 三个方向的大改混在一个提交里。

## v0.5.1

- 版本号：v0.5.1
- 日期：2026-07-08
- 改动目标：Android 自动刷新与设置页热修复。
- APK 输出路径：`releases/android/v0.5.1/bilibili-monitor-android-v0.5.1-debug.apk`

### 用户反馈

- v0.5.0 实机界面没有看到设置页，也没有看到 15m / 30m / 1h / 3h / 6h 和仅 Wi-Fi 设置入口。
- 自动刷新没有观察到执行，也没有明显日志或历史记录变化。

### 问题原因

- 设置页 Composable 和 Page 分支存在，但导航入口放在普通单行 `Row(fillMaxWidth)` 的最后一个按钮；手机窄屏下按钮不会换行，也不能横向滚动，导致“设置”入口可能被裁掉。
- 自动刷新默认关闭，设置入口不可达时用户无法开启 WorkManager。
- v0.5.0 只写了日志，没有在设置页显示 WorkManager 注册状态、最近注册时间、最近执行开始/结束、结果和错误，实机无法区分“未注册”和“已注册等待系统调度”。

### 修复内容

- 顶部导航改为 `LazyRow`，窄屏可横向滚动。
- 首页新增“自动刷新设置”按钮，提供明确入口。
- 设置页显示自动刷新开关、当前间隔、网络约束、WorkManager 注册状态、最近注册/取消、最近开始/结束、结果和错误。
- DataStore 新增自动刷新诊断字段。
- Worker 执行开始、结束、失败和关闭跳过都会写入 DataStore 诊断状态。
- 新增可测试的自动刷新注册控制器，覆盖开启注册、关闭取消、间隔/网络约束变更重调度。
- 新增 Worker 状态文本测试，覆盖无视频结果和失败状态。
