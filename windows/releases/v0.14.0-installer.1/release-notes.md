电脑版 0.14.0 · 安装包第 1 版

- 首页统一识别 UP UID、空间链接、BV 号、视频链接及短链；按识别结果显示间隔设置，改善窄屏布局。
- 新增 UP 更新检测：首次建立基线，随后发现新投稿（含合作投稿）自动加入任务；支持独立间隔、暂停和移至任务列表。
- 新增一键重启检测与回收站永久删除；UP 新稿不设视频总量硬上限，到提醒阈值时显示提示。
- 区分网络超时、平台响应解析失败与登录态有效性；显示冷却倒计时，避免网络故障被误判为登录过期。
- 刷新保留现有页面及滚动位置，并显示加载状态；改善目录、过渡动画、竖屏封面及数据布局。
- HTML 报告在系统浏览器打开，支持删除及文件路径失效提示；精简重复的采集、演示入口与说明。
- 使用窗口化程序入口：关闭 CMD 调试设置时不创建启动控制台。

视频统计按任务间隔自动采集；评论和弹幕正文仍需手动启动或续采，不随统计间隔自动遍历。UP 新稿发现需要登录；已加入视频的统计使用匿名接口。平台限制、请求限速与冷却可能使检测延后，接口遍历不保证完整历史。

安装：退出程序后运行 Windows x64 setup.exe。同一 Windows 用户默认沿用原安装目录，保留运行数据。无需安装 Python，窗口依赖 WebView2 Evergreen Runtime。安装包未配置 Authenticode 签名；可使用 SHA256SUMS.txt 核对下载一致性。本次仅更新 Windows，不改变 Android 版本。
