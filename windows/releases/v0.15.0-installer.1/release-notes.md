# Windows 0.15.0 · 安装包第 1 版

本次仅更新 Windows。

- 评论、弹幕随视频统计安排采集；上一轮未完成时持续从断点续采，分批轮转，避免重复启动任务。
- 修复不可见楼中楼根评论、评论分页断点和弹幕分段兼容问题；带分 P 参数的任务仅抓指定 P。
- 共用 HTTP 连接和 SSL 上下文，默认请求启动间隔为 0.75 秒。
- 一个账号即可采集，推荐配置备用账号；确认原账号失效或退出后，备用账号可接管原断点。网络故障与平台限制保持独立退避，不通过换号绕过限制。
- UP 新视频自动更新到首页，显示当前检测加载状态；避免旧的中断状态和正在检测提示混淆。
- 优化等高设置布局、账号状态卡和局域网板块跳转；恢复普通页面淡入，刷新保持页面内容和滚动位置。

## 安装与更新

下载 Windows x64 安装包后退出程序再安装。同一 Windows 用户默认沿用已有安装目录，数据库、配置和登录态保存在用户数据目录。卸载保留这些数据。

本安装包未配置 Authenticode 签名。可用 SHA256SUMS.txt 核对下载文件。请求间隔并不保证吞吐率或平台允许频率；平台限制时程序保留断点并冷却。
