# Windows 0.15.0 发布安全检查

2026-10-11：官方 gitleaks 8.30.1 工具经官方 SHA-256 校验，扫描 Git 历史、已跟踪源码、实际 PyInstaller 载荷和 4,217 个冻结模块常量。没有发现应用凭据。

冻结常量扫描初次标记第三方 packaging.licenses._spdx 的 HIDAPI / Hippocratic 公共许可证标识符；该模块全部常量与安装依赖的原始常量逐项一致。仅排除这个已验证模块后复扫，零发现。完全脱敏的原始报告及常量留在私有临时目录，不上传。

载荷不含用户数据库、登录态、配置、日志、私钥或导出内容。唯一 PEM 是与 certifi 原包一致的公共 CA 证书。PE 子系统为 GUI（2）。独立测试 AppId 使用同一载荷，安装文件逐一比对，验证首次安装、原目录覆盖升级、报告和历史导出、配置写入、卸载数据保留；不替代真实安装、人工向导或干净虚拟机验收。

安装包未配置 Authenticode 签名。277 项源码测试通过。扫描可降低泄露风险，不能保证识别未知格式的所有敏感信息。
