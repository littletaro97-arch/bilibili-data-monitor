# Windows 0.13.0 第 1 版发布前检查

检查日期：2026-10-04。源码及待发布安装包已完成检查。

- 官方 gitleaks 8.30.1 下载包通过官方 SHA-256 清单校验，报告完全脱敏。
- Git 全历史扫描：未发现凭据；实际 PyInstaller 文件目录扫描：未发现凭据。
- 冻结 EXE 的 4,211 个模块字符串常量单独扫描，唯一候选是第三方 packaging.licenses._spdx 的 HIDAPI / hippocratic-2.1 公开许可证名称，人工核对为误报；未设置整文件忽略。
- 实际载荷无 .env、config.toml、登录态文件、业务数据库、运行日志、用户导出数据或私钥。Bilibili 登录功能的用户凭据在运行时由 Windows 当前用户加密存储，不随包发布。
- 安装验证逐文件校验了安装内容与已扫描暂存目录的 SHA-256；安装额外内容只包含卸载程序及安装说明。
- 188 项源码测试通过。用独立 AppId 和临时用户目录验证同一载荷的安装、原目录沿用、报告、导出、配置写入及卸载数据保留，未覆盖正式安装。测试包与正式包的差别为测试安装标识与输出路径。
- 本次不使用 Computer Use，不宣称逐页人工向导或干净 Windows 虚拟机验收。安装包未配置 Authenticode 签名；SHA-256 校验用于下载一致性验证。

扫描减少泄露风险，并非保证不存在任何未知形式敏感信息。只上传正式安装包、校验清单与本检查说明，不上传私有扫描日志、模块解包内容或用户数据。
