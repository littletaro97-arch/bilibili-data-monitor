电脑版 0.13.0 · 安装包第 1 版

- 更新自有窗口图标、深浅色模式、托盘及通知返回首页。
- 任务卡片点击进入详情；标题打开 B 站视频。支持逐任务修改采集间隔。
- 视频封面本地缓存，图表按需渲染，减少后台刷新与资源占用。
- 改善详情布局、悬浮目录、加减速动画和设置自动保存。
- 改善中文样本词提取，支持登录后评论翻页、楼中楼与分 P 分段弹幕的断点采集。
- 留存已采集原文及修改历史，区分上次可见、疑似删除占位及未核验；接口遍历不保证完整历史。

安装说明：请先退出程序再运行 setup.exe；同一 Windows 用户默认沿用原安装目录并保留数据。无需另装 Python；窗口使用共享 WebView2 Evergreen Runtime。

源码测试 188 项及隔离安装验证通过，包内敏感信息检查未发现实际凭据。下载可核对 SHA256SUMS.txt。本安装包未配置数字签名。
