# v0.11.1-installer.1 电脑版安装包

文件：`BilibiliMonitor-v0.11.1-installer.1-windows-x64-setup.exe`，约 47.5 MiB。
适用于 Windows 10/11 x64，内置运行时，无需另装 Python。
双击后按中文向导选择安装目录与快捷方式，安装完成可直接启动。

卸载入口在 Windows 应用列表和开始菜单。卸载时显示确认说明，保留用户数据。
默认数据目录为 `%LOCALAPPDATA%\BilibiliMonitor\runtime-data`。
旧源码版历史可先导出历史交换 ZIP，再在安装版设置页导入。
详细使用和卸载方法见同目录 `安装与卸载说明.txt`。

安装欢迎、说明、路径、开始菜单、快捷方式和确认页，以及卸载数据保留提示已查看实际画面。
