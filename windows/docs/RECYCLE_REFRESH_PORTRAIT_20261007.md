# 回收站、数量提醒、加载与窄屏布局迭代

日期：2026-10-07。基线 727ec6a，分支 codex/recycle-refresh-and-up-limits。先启动基线供用户查看，再在独立工作树修改，避免中间模板影响运行实例。版本号保持 0.13.0 第 1 版，本轮不打包、不推送。

## 永久删除

回收站新增二次确认的永久删除，只允许本机同源请求且任务仍为 stopped。先取消该视频的文本采集，再用一个事务删除任务、视频元数据、统计快照、评论、弹幕、修改前原文、文本采集记录/断点和该视频日志。正在运行或已被取回的任务拒绝删除。独立导出的报告、CSV/ZIP 等文件保留。UP 发现表仅保留最小删除标记和 BV，清空标题，阻止下轮自动加回；手动重新添加仍可开始新的记录。

## 数量与调度

UP 自动新增视频不再受手动任务上限阻止，总存储数量不设硬上限。原 max_active_tasks 用于手动任务上限及首页置顶数量提醒阈值；达到阈值提示用户回收或永久删除不需要的任务。旧自动任务有明确 UP 来源标记时迁移为 automatic，导入快照不被当作该来源证据。

保持全局请求限速和现有采集并发。每轮 UP 投稿扫描最多十页，未完成时保存重叠一页的分页断点和已发现 BV，下轮续接；不再因超过 300 条永久报错，也不把单轮请求预算当总数量上限。新视频入队每轮十条，其余持久化待加入。自动统计调度用有界批次（默认每轮四条），避免总任务增加时一次创建全部协程；托盘全体检测也分批执行。大量任务会延后单个视频实际采集时间，不能保证每个任务都达到设置频率。平台分页并非原子快照，扫描期间的大规模删除/重排仍可能造成平台返回范围变化。

## 页面加载与位置

去除导航/提交前的正文淡出并保持透明逻辑；等待原生导航响应期间旧页面保持可见。集中到 navigation.js 的操作加载标志、防重复提交和位置记录，异步登录/遍历请求用同一个标志组件，不重建整页。页面切换保留轻微位移和 0.96 到 1 的入场效果，刷新不进行整页入场透明动画。

通过 sessionStorage 在离开前记录滚动位置及可见任务/章节锚点；同一路径响应和普通刷新恢复当前位置，连等待期间用户继续滚动也保留。新增置顶提醒或消息改变页面高度时，优先保持原可见区块的位置。页面内容被删除到不足原高度时由浏览器自然限制滚动范围。按钮/链接显示 CSS 加载标志，后台刷新显示轻量状态；尊重减少动态效果。没有引入前端框架或手动 document.write 换页，避免脚本重入和计时器泄漏。

## 窄屏

1100 CSS px 以下，目录以半透明浮层覆盖页面，不再预留左右宽度。右上角 × 仅隐藏当前详情访问，刷新仍隐藏，离开该页面后恢复；不修改持久开关。目录仍用 IntersectionObserver/ResizeObserver，无滚动轮询或背景模糊开销。

中等窄屏把四个概况信息格与操作按钮移到封面/标题下一整行，仍保持三列两行；更窄时改为两列，并把按钮放到下方。最新数据在 360–1100 px 下使用两列，时间格不跨两列，和数据来源同排；更窄时自然单列。

## 清理与验证

删除已退役的单页/XML快捷采集、本地导入和演示 HTTP 路由及生产启动时的 Phase2Service 实例；离线测试工具保留。分 P 元数据读取迁入 VideoService，保留 60 秒点击冷却和原数据记录。删除未使用的旧报告扫描函数、重复导航退出动画、无引用动画和未使用导入；保留兼容重导出以及核心数据/报告/历史交换代码。

回归包括：永久删除状态/事务边界与断点取消、保留导出文件、UP 删除抑制、350 条分轮发现、有界调度、慢提交期间旧页可见及加载标志、等待中滚动与普通刷新恢复、980 px 概况/时间并排、目录临时关闭及不改持久偏好。

本轮测试用隔离数据和无头浏览器，不使用 Computer Use。最终全套回归 **213 项通过**，包括永久删除接口和有界批次验证。真实长时间高负载及用户视觉体验由验收确认。回滚用 git revert；新字段为幂等追加列，旧程序忽略字段，永久删除的数据需从事先备份恢复。
