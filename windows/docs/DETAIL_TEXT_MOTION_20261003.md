# 详情时间、轻动画与公开文本采样

基线 `2c5ea52`，分支 `codex/detail-motion-text-collection`。本地提交，不打包、不推送。没有操作用户窗口或修改用户数据。

## 时间显示

最新数据的采集时间使用现有本地时间过滤器，显示 `2026-10-03 20:41`，不显示微秒和时区后缀。桌面时间卡占两列并保持单行，窄屏回归单列。鼠标悬停可查看完整原值；定时刷新同样格式化，不修改数据库时间精度。

## 动画与开销

所有原生 details（含嵌套图表、设置日志和排错说明）展开与收起增加 160ms 局部高度与透明度过渡。连续点击会取消旧动画并从当前高度过渡，结束后清理裁剪状态。图表仍使用已有实例，不重新创建或重新获取数据。

页面进入为 160ms 透明度和 4px 位移，同源链接离开为 120ms 透明度过渡，包括设置、回收站、返回首页与详情。下载、外链、当前页锚点和修饰键点击保持浏览器行为；表单提交只应用新页面进入动画，不延迟保存操作。历史缓存恢复时清理离场动画。支持系统减少动态效果偏好；不增加定时器轮询、永久 will-change 或页面截图过渡。

## 评论与弹幕

使用公开接口 `https://api.bilibili.com/x/v2/reply`，请求参数为视频 aid、type=1、pn=1、ps≤20、sort=2。不读取 Cookie，不登录，不签名或绕过平台限制，不翻页或追加子评论请求。每条主评论最多保存接口附带的 5 条回复，保留文本、作者、点赞、回复数与时间；评论 ID 使用字符串避免精度损失。同一评论再次采集更新原记录。

弹幕继续使用已有的 `https://comment.bilibili.com/{cid}.xml`，保留视频内时间、发送时间和文本。增加异常 XML、DOCTYPE/ENTITY 声明与解析前文本大小保护，最多保留 10,000 条非空样本。8MiB 限制作用于下载后的解析阶段，不是流式网络下载限额。该接口返回的是公开视频弹幕样本，不是完整历史，也不代表全部分 P。

两类采集均由用户手动触发，不加入监测定时任务。接通原有配置里的最小间隔，默认同类全局间隔 600 秒、最低 60 秒，成功与失败均进入冷却，并发连续点击也被限制。冷却保存在进程内，重启后重新计时。现有统计采集与其共用网络客户端请求间隔；平台风控异常沿用客户端停止重试行为。保留文本导入与演示数据。
