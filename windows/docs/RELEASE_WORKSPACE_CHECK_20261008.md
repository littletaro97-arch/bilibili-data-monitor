# Windows 0.14.0 发布后工作区检查

所有工作树无未提交业务修改。本次发布基于已验收 85e1d23，构建源 d2aa017；标签 windows-v0.14.0-installer.1 指向 e7025e7，版本记录与正式安装包均保留。公开仓库及 Release 已核对；旧版实际更新器可识别新包，无凭据公开下载大小和摘要一致，匿名 API 出口存在 403 限流。

清理范围仅本次 release-014 工作树 windows/build 和 windows/dist（约 211.3 MiB，均为可重建忽略产物），正式 setup.exe 保留在 windows/releases/v0.14.0-installer.1。用户运行目录、注册安装、数据库备份、导出报告、Git 分支/标签和旧迭代工作树不删除。私有安全扫描与安装检查证据在系统临时目录保留。

canonical 仓库与旧工作树没有未提交修改，旧构建载荷及历史运行目录暂不清理，防止误删回滚材料。当前验收程序继续从 compact-entry 运行，没有自动安装新 Release 到用户正式安装目录。后续开发从发布分支或同一标签开始，避免混用 0.13.0 的旧工作树。
