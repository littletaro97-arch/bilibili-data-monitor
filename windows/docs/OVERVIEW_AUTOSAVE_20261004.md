# 概况布局与设置自动保存

- 视频概况的四个信息格收窄；右侧上下排列“打开 B 站视频”和“打开 HTML 报告”，形成三列两行。650 px 以下按钮改为底部并排，避免窄屏文字溢出。
- CMD 开关、局域网开关切换后自动保存；密码输入完成后离开输入框自动保存。取消两个保存按钮，返回明确成功/失败消息。显示密码开关直接生效，不提交配置。
- 自动保存并不热切换监听地址或新建/销毁 CMD 窗口。局域网监听仍需重启，CMD 设置仍在下次启动生效；保留明确提示，避免重启中断正在采集的文本任务。
- SESSDATA 默认展开；标题、说明、标签、输入框、验证按钮保持间距。账号凭证仍只通过原验证接口提交，不做自动保存。
- 验证覆盖自动保存接口、无密码启用失败、开关自动提交、密码离焦保存、显示密码即时切换、三列两行几何位置和窄屏不溢出。未使用 Computer Use。
- 本地提交供验收，验收通过前不推送 GitHub、不打包。
