# 不可见根评论和正文通道排队修复

日期：2026-10-09。源码基线：1b84663，分支 codex/synchronized-text-capture。
范围：本地源码和 Git；不升版本、不打包、不推送、不发布 Release，不修改或重启现有采集进程。

## 根评论不可见

此前楼中楼接口 `/x/v2/reply/reply` 返回 code=12006 时，整个评论任务暂停在同一个根评论，重试也无法前进。
现在仅对该接口的明确 12006 返回使用专门异常：保留根评论和已采集回复的原文，将根评论标记为“平台已不可见（原文保留）”，结束该根评论的楼中楼读取，继续其它根评论和下一页。UI 和日志记录不可见根评论数量。
“不可见”并不能证明删除；不将已有回复统一标为删除。后续成功观测到同一根评论时，恢复“上次采集可见”。其它平台错误、风控、网络异常和坏游标仍保留断点并按原规则处理。

旧版已暂停且明确因 12006 失败的自动评论任务，在下次启动时只做一次兼容重试；保留原任务 ID 和 pending 游标，重新请求确认后才跳过。手动暂停的任务不会自动恢复。

## 手动排队与状态更新

正文通道忙碌时，手动开始或续采进入持久化队列，不再要求先暂停其它视频。通道空闲后由原一秒调度器启动；重复续采同一运行中或排队任务不会生成第二个执行任务。排队可以取消，取消保留断点。
保持单正文工作线程、原分 P 范围、手动批次上限、账户绑定、登录验证和平台冷却。视频统计的自动安排不会将排队中的手动任务改成自动无限续采。排队分发前重新校验登录及账户。显式手动请求仍支持视频统计暂停或未建立统计任务的本地视频；回收站视频不能执行。

前端采集操作无论成功或失败，都恢复三秒状态轮询；失败提示先显示，下一次轮询继续更新当前任务进度。
