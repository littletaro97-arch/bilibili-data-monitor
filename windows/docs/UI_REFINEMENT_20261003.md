# 2026-10-03 设置与回收站优化

基线：`0433957`。分支：`codex/windows-switches-navigation`。仅本地 Git，不打包、不推送，不修改用户的采集任务或配置。

## 改动

- 回收站内容上方加入“返回首页”，复用设置页的 `.page-actions`，位置和按钮样式一致。
- 全局根元素使用 `scrollbar-gutter: stable`，在长页与空回收站之间预留相同滚动条空间；不支持该属性的浏览器回退为保留纵向滚动槽。
- CMD 调试窗口、局域网访问、显示输入密码三个勾选项改成图标＋文字＋右侧滑动开关的卡片。沿用现有青绿色和深浅色变量，支持整卡点击、Tab 聚焦、Space 切换及可见焦点。保留原生 checkbox、原表单字段与保存按钮；仅“显示密码”即时切换输入框显示方式，不自动保存其它设置。
