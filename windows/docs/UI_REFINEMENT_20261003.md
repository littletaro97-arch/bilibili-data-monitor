## 改动

- 回收站内容上方加入“返回首页”，复用设置页的 `.page-actions`，位置和按钮样式一致。

## 开关样式加载修复

用户验收发现 SVG 被放大成黑块、原生勾选框仍显示。上一轮验证使用独立的新 WebView2 配置，遗漏了共享 CSS 缓存旧内容的场景，不能据此认定用户现有窗口的显示已经通过验收。服务端样式包含开关规则，而截图显示这些规则没有生效，与旧样式缓存一致；未操作用户窗口检查其缓存，因此缓存原因仍是推断。

- 共享 CSS 地址增加版本参数，使新页面请求新的资源地址。
- 将开关关键样式直接随设置页 HTML 返回，避免旧共享 CSS 或共享样式加载失败导致开关退化。
- SVG 本身明确设置 24×24 尺寸、无填充和描边属性，避免缺少样式时放大成黑块。
- 新增可选的无窗口 Playwright 回归测试：模拟缺少开关规则的旧共享 CSS，以及共享 CSS 返回 404，验证三个卡片、24px 图标、50×30px 开关、隐藏原生勾选框、整卡点击、Space 切换和密码显隐；共享 CSS 可用时验证深浅色配色。
- 135 项测试通过（启用无窗口渲染和既有原生托盘测试）。渲染请求使用隔离数据与 TestClient，未写入用户配置，未启动桌面窗口。
- 已查看后台生成的开关卡片截图；当前运行服务的只读 HTTP 检查确认设置页包含内嵌开关样式、带版本参数的 CSS 地址和 SVG 尺寸保护。没有使用 Computer Use，没有操作或重启用户应用。用户离开设置页后重新进入即可加载新 HTML；实际窗口的最终显示仍由用户验收。
