# 统一添加入口与无控制台启动

日期：2026-10-08。基于 d8cfb80，分支 codex/unified-input-and-no-console。先打开已提交基线供用户验收，再在隔离工作树修改。版本号维持 0.13.0 第 1 版，本轮不打包产品安装包、不推送、不发布。

## 统一输入

首页顶部保留一个输入：UID（含 UID：123）、UP 空间链接、BV 号、视频链接或 b23.tv 短链。后端按明确链接类型分类：空间/UID 进入 UP 检测，视频链接进入视频任务；不再把视频链接反查作者后误当作 UP 添加。短链仅解析官方 HTTPS 跳转，解析后可归为 UP 或视频，不请求未知域名。

客户端提供即时提示；UP 和待解析短链展示 UP 检测间隔，明确视频输入隐藏该字段；视频采集间隔统一保留，UP 模式在用户尚未编辑时使用记住的新稿默认间隔。支持全角数字 UID、域名/协议大小写。最终分类以后端为准，UP 添加仍仅本机同源，并复用已有登录态、初始基线和任务归类。

移除 UP 区块的第二套添加窗口，保留各 UP 的检测、暂停/恢复、移除、后续间隔调整和新视频分组。

## CMD 闪现根因与修复

旧正式安装 EXE 的 PE 子系统为 3（控制台），原构建脚本也指定 --console。Windows 在 Python 读取 show_console=false 之前就可能创建窗口，所以只在入口里再隐藏/脱离不能保证无闪现。

后续构建统一改 --windowed，入口本身不创建控制台；仅 show_console=true 时按需连接/创建调试控制台。hidden 与 detached 创建标志不再混用。窗口化/冻结环境下先补齐缺失 stdin/stdout/stderr，日志写入原运行目录，防止 Uvicorn 因无标准流退出。原隐藏模式的子进程重定向与 CREATE_NO_WINDOW 保留。

本机有效配置 show_console=false；本轮不更改设置。旧已安装的 console EXE 未被覆盖；其初始闪窗需要以后用新配置构建并升级安装包才能消除，修改源码不能改变旧 EXE 的 PE 子系统。

## 验证

全套隔离回归 **234 项通过**。额外无头验证统一入口只有一个窗口，UP 字段按类型自动展示/隐藏，并能成功归入 UP/视频任务。覆盖短链到两类目标、非法/多目标、非官方跳转、端口/URL账号密码、本机登录权限、GUI 标准流、关闭 CMD 时不分配控制台及构建标志。

临时 PyInstaller GUI 探针使用实际启动器标准流初始化代码；PE 子系统为 2，在 creationflags=0（未强行隐藏）的启动下，初始化前后控制台句柄均为空，Uvicorn 日志初始化成功。探针仅存临时目录，不是项目安装包，也不代表整个产品在所有 Windows 设备上的验收。脱敏结果见 evidence/20261008/windowed-boot.json。
