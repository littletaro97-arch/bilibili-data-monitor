## 错误与登录状态

请求异常区分 timeout / network / http / parse；显示超时、连接失败、HTTP 状态码或 JSON 解析失败，不输出异常原文、Cookie、请求头或响应正文。HTTP 403/412/429 保持风控停止重试。普通视频连续网络超时/连接失败不再因累计三次而永久进入 error，而是继续按冷却计划自动重试；解析和其他异常仍保留原停止策略。

登录文件保存与平台验证分开：未验证、上次验证有效、平台明确失效、本次无法验证。记录上次成功验证时间；断网和解析错误不冒充登录过期，不清空凭据。设置新增“验证登录态”，与采集请求共享限速，无额外后台登录轮询。没有实现自动刷新或延长平台 Cookie 有效期。

任务卡片和 UP 显示冷却剩余时间，单个轻量定时器每 5 秒更新；隐藏/最小化时跳过 DOM 更新。UP “立即检测”被冷却、暂停或进行中的请求阻止时，会明确给出原因，不再报告操作成功。

## 一键重启检测

主页按钮统一安排视频与 UP 检测到期，交由原 10 秒调度器执行；不是重启 Windows 或应用进程，也不在请求中等待全部网络采集。

- 可提前解除有明确 timeout/network 标记的普通故障冷却。
- 保留手动暂停、回收站、进行中的检测、尚未结束的风控/未知类型冷却及任务数量上限。
- 登录失效的 UP 只有在最近五分钟平台验证成功后，才可由此按钮恢复；否则保持待登录。
- 重置被安排任务的连续失败计数；历史日志、快照、UP 基线、待加入项与原采集间隔保留。
- 不自动恢复独立、手动运行的评论/弹幕遍历任务。
- 入口仅允许本机、同源操作，并显示安排和跳过数量。
