# 添加入口与说明精简

基于 ebf4207，分支 codex/compact-entry-and-login-guidance。版本号保持 0.13.0 第 1 版，仅本地 Git，未打包、推送或发布。

输入框保留可访问名称和占位文本。空输入或不能识别时隐藏并禁用间隔字段；输入停顿 250ms 后使用同一后端分类器识别，短链仅通过现有官方 HTTPS 白名单解析。预览不添加任务，不读取登录态，不触发采集；取消过时客户端请求，只有当前输入对应结果能改变界面。视频显示视频间隔；UP 显示新视频采集间隔和 UP 检测间隔。窄于 1100px 时，输入与添加按钮在第一行，两个间隔在下一行；480px 以下分行，避免输入框旧最小宽度导致重叠。

删除本轮指定的添加、UP 说明、正文检视提示、分 P 提示、词语方法文案、版本更新说明和托盘说明。保留相关功能与验证规则。未保存登录态时显示登录建议：视频统计可直接采集，UP 新稿发现需要登录。已有匿名视频接口未改变，不向视频统计请求注入登录 Cookie。

调度检查：TaskScheduler 每 10 秒检查到期视频任务与 UP 任务，视频统计按单任务用户间隔安排（可能受请求限速、风控冷却与队列延后影响）。评论和弹幕正文由 FullTextService 手动启动或续采，不受视频统计间隔调度。统计快照包含平台评论/弹幕数量，数量更新不等于正文采集。

验证：无头浏览器检查初始隐藏、视频/UP 识别、760px 两间隔下一行且互不重叠、360px 无水平溢出、添加后归类及已有报告/动画功能。接口预览检查非法域名、短链解析和无任务写入；完整回归结果见本轮最终回复。打开时沿用本机运行数据并先备份数据库，旧工作树保留作回滚。
