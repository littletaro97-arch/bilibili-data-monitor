# Windows workspace boundary

This is the standalone Windows/Python/FastAPI working tree. Run and test it from this directory; its local data stays under `runtime-data/`.

It contains a mirrored `shared/history-exchange/` contract. Do not add Android Gradle source, APKs, Android device data, or Android build caches here. Any shared-contract change must be mirrored to `E:\Bili-monitor\bilibili数据监控-android\shared\history-exchange` in the same iteration.

The pre-v0.11.0 local data backup is retained under `workspace-history/local-backups/` and is not active runtime data.
