# Project overview

- Windows application, tests and launcher: `windows/`
- Android application and Gradle project: `android/`
- Shared exchange contract and schemas: `shared/`
- Windows releases and history: `windows/releases/` and `windows/history/`
- Android releases and history: `android/releases/` and `android/history/`
- Cross-platform development documents: project root
- Windows runtime data: ignored `windows/runtime-data/`

Each platform builds and tests from its own directory. Shared contains schemas, examples and test vectors only.
